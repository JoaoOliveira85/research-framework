# Contract: Vault Factory (`tests/_helpers/vault_factory.py`)

**Status**: v1 (feature 018)
**Producer**: `tests/_helpers/vault_factory.py`
**Consumers**: `tests/pipeline/test_full_cycle_e2e.py`, `tests/pipeline/test_multi_cycle_e2e.py`.

## a) Python API

```python
def build_minimal_vault(
    tmp_path: Path,
    *,
    num_categories: int = 3,
    num_targets_per_category: int = 5,
    max_cycles: int = 5,
    note_type_folder: str = "01 - Concepts",
    spec_overrides: dict | None = None,
    install_fake_agent: bool = True,
) -> Path: ...
```

Returns the absolute path to the freshly built vault root. The
`spec_overrides` mapping is merged on top of the default
`SpecConfig` (top-level keys win, nested keys replace whole subtrees —
explicit overrides win without surprise merging).

When `install_fake_agent=True` (the default for tests), the factory
overwrites `<vault>/scripts/agent_call.py` with a shim that
`subprocess.execvp`s into `tests/_helpers/fake_agent.py` — so the real
`cycle_runner.py` invokes the fake without modification.

## b) Post-conditions

The returned `vault` MUST contain:

1. **`research.spec.md`** — minimal spec markdown (does not need to round-trip via `spec.simple.load`; `spec-parse.json` is the canonical source for the cycle).
2. **`settings.yaml`** — minimal pipeline settings:
   ```yaml
   pipeline:
     gates:
       cg_003_warn_pct: 30
       cg_003_fail_pct: 60
     note_writer_batch_size: 6
     max_batches_per_cycle: 10
   ```
3. **`_pipeline/spec-parse.json`** — full `SpecConfig.to_dict()` plus `location` resolved.
4. **`_pipeline/coverage-targets.json`** — `CoverageTargets.to_dict()` (zero `met_count` initially).
5. **`_pipeline/prompts/scout-prompt.md`** + **`_pipeline/prompts/dfs-prompt.md`** — minimal prompts with `{CYCLE_NUM}` / `{SCOUT_REPORT}` / `{RESEARCH_REPORT}` placeholders. The cycle runner renders these into `cycle-NNN-*.rendered.md` before passing to the fake agent.
6. **`_pipeline/research-plan.md`** — generated by `pipeline.research_plan.generate_plan(spec, vault)` so the cycle runner's batched DFS path activates (the legacy no-plan path skips batches and breaks our asymmetric-tail scenario).
7. **`_pipeline/research-backlog.md`** — empty backlog header.
8. **`scripts/`** — the real bundled scripts (`vault_metrics.py`, `validate_cycle.py`, `validate_vault.py`, `check_template_compliance.py`, `check_acronym_links.py`, `topic_harvest.py`) plus the fake `agent_call.py` (when `install_fake_agent=True`).
9. **`.agents/skills/`** — at least `scout/SKILL.md` and `note-writer/SKILL.md` copied from the bundled `.agents/skills/` so `skill_check.validate_and_repair_skills` has something real to scan. Missing-skill behavior (zero scanned → OK) is also acceptable but the explicit copy lets us cover the "corrupted skill auto-repairs" scenario.
10. **`data_vault/<note_type.folder>/`** — empty per-category folders so the note-writer has somewhere to land notes.

## c) Post-condition validation

After `build_minimal_vault(tmp_path)` returns, the following invariants hold:

- `python scripts/validate_vault.py <vault>` exits 0 (no false-positive failures on a fresh vault).
- `python scripts/agent_call.py --vault <vault> --stage scout --prompt-file <any> --cost-sidecar <path>` exits 0 and produces a v2 scout JSON that validates.
- `python scripts/validate_cycle.py <cycle-NNN-scout.json> --vault <vault>` exits 0 (CONTINUE) for a fake-agent-produced scout in `happy` mode.

## d) Determinism

For a fixed `(num_categories, num_targets_per_category, max_cycles, note_type_folder, spec_overrides)` tuple, the factory produces a byte-identical vault layout (modulo the `tmp_path` prefix). All iteration uses `sorted()`; no `time.time()` or `uuid` is used in spec generation.

## e) Cost

A factory invocation must complete in **< 1 second** on a modern laptop. Tests that need multiple vaults use a per-function `tmp_path` (no shared-fixture optimization — see plan § Risks).
